# Grid Maker

[Grid Maker](https://gridmakering.com/) is a free browser-based drawing tool that turns reference photos into customizable grids for more accurate proportion studies.

## Features

- Upload JPG, PNG, or WEBP reference images up to 20 MB.
- Adjust rows, columns, line color, width, opacity, and optional A1-style cell labels.
- Preview the result and export the finished grid as PNG or JPG.
- Process images locally in the browser; images are not sent to an image-processing server.
- Use the tool on desktop or mobile without creating an account.

## Try it
